# S2A Rate Bot 暖石色双主题设计

## 目标

将 `s2a-rate-bot` 全部界面的配色迁移为参考页面的暖石色视觉体系，并提供可切换的浅色与暗色主题。

- 浅色主题采用暖米色背景、白色半透明表面和 Stone 中性色。
- 暗色主题采用深棕黑径向背景、深 Stone 表面和高对比文字。
- 琥珀色用于主要操作、当前导航和重点数据。
- 成功、警告、错误和信息状态继续使用绿、琥珀、红、蓝语义色。

## 主题架构

在 `globals.css` 中定义语义 CSS 变量，组件只引用语义 token，不直接依赖 `slate-*` 色阶。主要变量包括：

- `--background`、`--background-accent`
- `--surface`、`--surface-muted`、`--surface-elevated`
- `--foreground`、`--foreground-muted`
- `--border`、`--border-strong`
- `--primary`、`--primary-foreground`、`--focus-ring`
- `--success-*`、`--warning-*`、`--danger-*`、`--info-*`

浅色变量定义在 `:root`，暗色变量定义在 `.dark`。Tailwind 配置将颜色名映射到这些变量，使现有组件能使用稳定的语义类名。

## 主题切换

在应用壳层增加明暗主题切换按钮，使用太阳和月亮 Lucide 图标并提供可访问名称。

主题解析顺序：

1. 如果 `localStorage` 中存在用户选择，使用该选择。
2. 否则跟随 `prefers-color-scheme`。
3. 用户切换后保存到 `localStorage`。

在文档加载早期执行内联主题初始化脚本，在 React 水合前设置根元素的 `dark` 类和 `color-scheme`，避免页面先显示错误主题再闪烁。

## 组件迁移范围

以下界面全部迁移到语义颜色：

- 应用背景、粘性顶部导航、当前与非当前导航项。
- Worker 状态面板和状态徽章。
- 分组倍率页面的卡片、规则表单、开关和错误信息。
- 倍率采集页面的操作按钮、采集站表格、倍率表格和新增/编辑弹窗。
- 账号调度页面的桌面表格、移动卡片、状态徽章和调度开关。
- 全局配置页面的分区、输入控件、开关和测试反馈。
- 登录/初始化弹窗、遮罩层、加载态、空状态和错误态。

布局、业务行为和页面信息结构保持不变。

## 视觉层级

- 页面背景使用低对比径向渐变，不能影响正文可读性。
- 顶部导航与内容卡片使用半透明表面、轻边框和统一阴影层级。
- 当前导航和主要按钮使用琥珀色；普通导航使用次级表面。
- 表格表头使用次级表面，行分隔使用默认边框。
- 弹窗使用最高表面层级，遮罩保持约 50% 黑色透明度。
- 焦点环在两套主题中均清晰可见，不能移除键盘焦点反馈。

## 可访问性

- 普通正文与背景对比度至少达到 WCAG AA `4.5:1`。
- 大文本、边框和图标至少达到 `3:1`。
- 运行状态不能只依赖颜色，保留现有文字标签和图标。
- 主题切换按钮保持至少 `44px × 44px` 的点击区域。
- 颜色过渡控制在 `150–300ms`，并尊重 `prefers-reduced-motion`。

## 测试与验证

实施前增加失败测试，覆盖：

- Tailwind 已启用基于 class 的暗色模式和语义颜色映射。
- 根布局包含水合前主题初始化逻辑。
- 应用壳层包含可访问的主题切换控件。
- 组件源码不再使用旧的 `slate-*` 配色类。

实施后运行完整测试、TypeScript 类型检查和生产构建。视觉验证覆盖浅色与暗色的 `375px`、`768px`、`1024px` 和 `1440px` 视口，重点检查导航、表格、卡片、表单和弹窗的对比度及横向溢出。

## 非目标

- 不调整页面布局或业务功能。
- 不引入新的 UI 组件库。
- 不更换 Lucide 图标体系。
- 不修改采集、规则计算、账号调度或设置 API。
